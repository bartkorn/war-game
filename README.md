# War Game

A simple Python implementation of the classic **War** card game. Built as a learning project to explore Python packages and game logic. 

The application simulates a single round of the war game with a full deck of cards shuffled in random order. It implements basic mechanics of the card game and allows to configure the deck by modifying suites and ranks in ```config.py```.  

## Requirements

- Python 3.7+  

## Installation

Clone the repository:

```bash
git clone https://github.com/bartkorn/war-game.git
cd war-game
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the game

From the project root, run:

```bash
python -m war_game.game
```
